# День 22 — первый RAG-запрос

## База и условия эксперимента

Документ: [AI-Disrupt PDLC, версия 2.0, июнь 2026](https://aipdlc.ru/documents/ru/whitepaper_full_ru.pdf).
Ожидания ниже составлены по тексту PDF, а не по ответам модели. Утверждения и числа
считаются содержанием документа, а не независимо подтверждёнными внешними фактами.
Страницы указаны по порядку в PDF, начиная с 1: печатная страница 1 соответствует PDF-странице 5.

Для каждого вопроса выберите один COMPLETED-индекс и «Оба ответа».
Модель: `gpt-6.1-sol`; один профиль, одинаковый лимит ответа, без истории диалога.
Для проверки влияния chunking повторите вопросы отдельно на Fixed-size и Structural.
Top-K по умолчанию 5. Названия разделов и страницы — ожидаемые источники, не гарантированный результат поиска.
