# Документация проекта для RAG

Эта папка — поддерживаемый набор коротких документов о репозитории. Индексируйте
`README.md` и все Markdown-файлы из `project/docs/` в профиль, предназначенный для
вопросов о проекте. Не индексируйте секреты, `.env`, дампы БД, журналы или личные
данные.

проверкой доступности сервисов в реальном времени.
